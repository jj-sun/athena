**项目说明** 
- athena-boot是一个轻量级的，前后端分离的Java开发平台。
<br>

<br>

**技术选型：** 
- 核心框架：Spring Boot 4.1.2（Java 21）
- 安全框架：Sa-Token 1.45.0（JWT Simple 模式）
- 视图框架：Spring Framework 7.x（Spring MVC）
- 持久层框架：MyBatis-Plus 3.5.18
- 定时器：Quartz
- 数据库连接池：Druid 1.2.28
- 日志管理：SLF4J、Logback
- API 文档：nextdoc4j + springdoc
- 页面交互：Vue 3
<br>
